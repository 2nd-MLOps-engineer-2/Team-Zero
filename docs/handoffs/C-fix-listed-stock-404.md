# C S4 수정 — 목록 종목의 404

기준 `review/s4-c-v1` / `37e54515b340f6000ef523a788ca3a05a4a5a1e8`. 수신 검토 대기.

API `/stocks`가 광고한 종목의 daily/financials 조회가 404이면 Gold에 행이 없어도 FAIL이다. 목록 종목과 Gold에만 존재하는 종목을 구분하도록 목록 집합을 각 검사에 전달한다. Gold에만 존재하는 종목의 누락은 기존 행 집합 검사로 잡는다. 목록 종목이 정상적으로 `200`과 빈 목록을 반환하는 것은 허용한다. 두 번째 이후 일별 페이지의 404는 기존처럼 조회 오류다.

```bash
.venv/bin/python -m unittest discover -s analysis/tests -v
```

회귀 검사는 목록에만 있는 종목의 두 조회 404, 보고서 없는 정상 종목, 보고서 Gold가 없는 목록 종목의 재무 404, 후속 페이지 404를 다룬다. 기존 Gold-only 누락·HTTP 500/503·페이징·중복·값 대사 검사는 유지한다.

API·Gold·기존 증빙을 바꾸지 않고 C의 판정만 보강한다. 종료 코드 수정과 식별자 비교 수정은 별도 PR이다. 실제 DB/Delta·A 화면·출력 계약 합의는 여전히 별도다.
