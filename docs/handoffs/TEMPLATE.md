# 단계 전달 기록 양식

이 양식을 해당 단계 파일로 복사하고 실제 값을 기록한다. 이 파일 자체는 전달 완료 증거가 아니다.

## 전달 요약

| 항목 | 실제 값 |
|---|---|
| 단계·회차·대상 체크북/M ID | 미등록 |
| 전달자 → 수신 확인자 | 미등록 |
| 상태 | 미착수 |
| PR base·선행 integration SHA | 미등록 |
| 전달 원격 브랜치·전체 SHA·PR URL | 미등록 |
| 데이터·계약·계산 버전 | 미등록 |
| 포함/제외 범위·변경 파일 | 미등록 |

## 바로 실행할 방법

- 설치 버전·준비물·입력 경로·안전한 환경 설정: 미등록.
- 설치/시작/검사/종료 명령: 미구현. 검증된 실제 명령으로 교체.
- API 문서·화면·출력 위치: 미등록.
- 정상·NULL·빈 결과·오류 샘플과 기대값: 미등록.
- 원본·DB 변경/초기화 여부: 미등록. 파괴적 실행을 기본 절차로 넣지 않음.

## 전달자 검사

명령·실제 결과·기준 SHA·환경·실제/합성 입력·미실행 사유·증빙 위치: 미등록.

## 수신자 확인

수신자 기존 브랜치/HEAD·보존 방법: 미등록.  
수신 확인 브랜치/HEAD·반영한 전달 SHA: 미등록.  
실행한 검사·환경·결과·증빙: 미등록.  
충돌·계약 차이·수정 요청: 미등록.  
판정: 미확인 / 수정 필요 / 수신 확인 완료 중 실제 상태.  
확인자·확인일: 미등록.
