## C05·M07 연결: SF04 REVIEW의 원문 대조

누적 연속성 REVIEW 20행 중 로컬 원문이 있는 11행(보고서 6건)은 Silver의 YTD·Q3M이 **모두 해당 보고서 원문에 그대로 존재**한다(`sf04_review_documents`). 즉 Silver 추출 오류가 아니라 뒤 보고서가 앞 기간을 재작성한 보고서 간 차이다(해당 기업 모두 SF06 재작성 목록에 포함). 원문 없는 2022년 보고서 5건은 R2 입력 대기.

## 한계

오염 ZIP 실물을 직접 읽지 않았으므로 인코딩 혼합(CP949 6·무BOM 3 파일)처럼 수정 이력에 셀로 남지 않는 파일 수준 결함은 명세서 값만 인용한다. 정화 이력이 정답 원본과의 셀 단위 완전 일치를 보증하지는 않는다(정화 README 4.4).
