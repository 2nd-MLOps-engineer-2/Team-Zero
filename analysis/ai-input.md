# C11 AI 입력 규격 — c-gold-0.1.0 제안

모델 학습·정확도 평가는 이번 범위에 없다. `g_stock_daily_analysis`는 관측 종료 후 탐색·후속 실험용이며 실시간 장중 신호가 아니다.

## 특징·단위

- 키: `stock_cd`, `trd_dt`. 기업·시장·보고서·연결구분은 범주형/계보 메타다.
- 후보 수치: 1/5/20관측 가격·지수·초과성과, 5/20관측 외국인/기관/개인 수급 비율, 보유율 변화, 20관측 변동성, 시점 매출 YoY·영업이익률·영업CF/매출, 공시 경과일.
- 원 금액·수량은 문자열/Decimal 원본으로 보존하고, 모델 입력으로 변환하는 별도 단계에서 정밀도·스케일 정책을 기록한다. 비율은 소수 비율이다.
- 상태·가용성·검토 플래그는 별도 마스크로 제공한다. NO_DATA·WINDOW_SHORT·PRD_UNVERIFIED를 실제 0으로 대체하지 않는다. 임퓨터·스케일러가 필요하면 학습 구간에만 fit한다.
- 미래에 확정된 정정 이력을 소급해 사용하지 않는다. 현재 인계본이 완전한 최초 공시 버전 이력을 제공하지 않는 한계와 당시 구성종목 표본 편향을 기록한다.

## 시간순 분할 제안

보유 범위 2022-12-01~2026-06-30에 대해 train: ~2024-12-31, validation: 2025년, test: 2026-01-01~06-30. 모든 종목에 같은 날짜 경계를 적용한다. 종목·일을 무작위 섞어 분할하지 않는다. 구간 선택·정책은 후속 실험 전에 합의하며 데이터 분포·유효 표본 수를 보고한다.

후속 지도학습 예: 다음 **관측일** 종가 수익률 또는 해당 시장 대비 성과. 라벨은 별도 파일·모듈로 생성하고 특징에서 제외한다. 현재 출력에는 미래 라벨이 없다. 미래 h개 관측을 쓰는 라벨은 구간 말단 h개의 누수 여부를 검사하고 train/validation/test를 가로지르는 라벨을 제외한다. 관측 간격과 실제 거래소 연속일의 차이를 기록한다.

`co_move_cd`, `joint_improve_yn`을 예측 정답으로 삼는다면 이를 직접 계산한 동시점 성분을 그대로 특징으로 넣는 순환 평가를 피해야 한다. 본 규격은 그런 예측 과제를 확정하지 않는다.

## B 인계

저장·API·다운로드에서 키·날짜·소수 비율·큰 정수·NULL·상태·계산 버전을 보존한다. 입력/출력 해시·스키마·실험 분할·특징 목록을 고정한 뒤 실제 학습을 별도 단계에서 시작한다. 이 문서 작성만으로 AI 모델·DB·배포 완료를 표시하지 않는다.
